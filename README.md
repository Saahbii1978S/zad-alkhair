# زاد الخير

موقع إسلامي عربي باتجاه RTL، يهدف إلى تيسير الأذكار والأدعية والتعلّم اليومي.

## المحتوى
- آية اليوم
- أذكار الصباح والمساء
- أذكار ما بعد الصلاة وأذكار النوم
- أدعية من القرآن والسنة
- أسماء الله الحسنى
- قصص الأنبياء
- تعلّم الوضوء والصلاة
- عدّاد التسبيح ومتابعة العبادات
