# زاد الخير

موقع إسلامي عربي باتجاه RTL، يجمع الأذكار والأدعية ومواقيت الصلاة والقرآن الكريم.

## الموجود في الموقع
- أذكار الصباح والمساء وبعد الصلاة وقبل النوم، مع عدّادات متابعة محلية.
- مواقيت الصلاة حسب البلد والمدينة، مع الصلاة القادمة والعدّ التنازلي.
- إعدادات تنبيه الأذان؛ التنبيه الصوتي الحالي يعمل أثناء بقاء الموقع مفتوحاً فقط.
- قارئ القرآن بالنص العثماني مع تشغيل الآيات بعدة خيارات للقرّاء عبر AlQuran Cloud.
- حفظ نص السورة المختارة على الجهاز للقراءة دون إنترنت بعد فتحها وحفظها.
- اتجاه القبلة بالحساب الجغرافي، والبوصلة عند دعم الهاتف لها.
- ختمة شخصية محلية من 30 جزءاً، ومشاركة دعوة الختمة عبر واتساب.

## حدود النسخة الحالية
- تقدم الختمة الجماعية لا يتزامن بين الهواتف بعد؛ يلزم backend وقاعدة بيانات مشتركة.
- الأذان لا يعمل بشكل مضمون عند إغلاق الموقع أو إيقاف المتصفح.
- نسخة Android APK أصلية وتنبيهاتها الخلفية ما زالت تحتاج مشروع Android واختبارات منفصلة.
- يلزم اتصال بالإنترنت أول مرة لتحميل فهرس القرآن والسور، ويمكن حفظ نص السورة المختارة محلياً.

## مصادر البيانات
- مواقيت الصلاة: AlAdhan API.
- نص القرآن والتلاوات: AlQuran Cloud API/CDN.

لا تُضاف مفاتيح أو أسرار خاصة إلى المستودع.
